  📋 액막이 명태: 시스템 인프라 구축 및 배포 명세서 (Technical Spec)

  > 작성일: 2026년 6월 8일  
  > 상태: 백엔드/DB 구축 완료, 도메인 연결 및 HTTPS 적용 대기 중

  1. 서버 인프라 (AWS EC2)
   * 인스턴스 유형: t3.micro (vCPU 2, RAM 1GB)
   * OS: Ubuntu 24.04 LTS (resolute)
   * 스토리지: EBS 30GB (8GB에서 확장 완료)
   * 중요 설정 (Swap): 
       * 경로: /swapfile (2GB)
       * 이유: 1GB RAM 부족으로 인한 프론트엔드 빌드 시 서버 다운 방지. free -h로 확인 가능.

  2. 데이터베이스 (PostgreSQL)
   * DB명: myeongtae
   * 유저: myeongtae_user (PW: myeongtae1234)
   * 연결 방식: pg.Pool (Connection Pool) 적용 
       * 파일: backend/src/db.js
       * 특이사항: 단일 클라이언트 방식에서 안정성을 위해 풀링 방식으로 리팩토링됨. 최대 20개 연결 유지.
   * 권한: GRANT ALL ON SCHEMA public TO myeongtae_user; 적용됨.

  3. 백엔드 서비스 (Node.js & PM2)
   * 런타임: Node.js v22.22.3 (nvm 관리)
   * 프로세스 매니저: PM2 (프로세스명: myeongtae-back)
   * 환경 변수 (.env):
       * 경로: ~/Aek_Maki_Myeongtae/backend/.env
       * Git 미포함 항목: JWT_SECRET, OPENAI_API_KEY, TOSS_CLIENT_CERT_PATH 등 수동 기입 완료.
   * 인증서 (Certs):
       * 경로: ~/Aek_Maki_Myeongtae/backend/certs/
       * 파일: aekmagi-ai_public.crt, aekmagi-ai_private.key (토스 mTLS 통신용, 수동 생성됨)

  4. 프론트엔드 빌드 및 배포
   * 빌드 도구: ait build (Apps in Toss 전용 빌드)
   * 빌드 결과물: ~/Aek_Maki_Myeongtae/frontend/dist/web
   * 서빙 경로: /var/www/myeongtae/web (Nginx가 직접 읽는 경로)
   * 연결 주소 설정: frontend/src/utils/api.ts 내 BASE_URL이 현재 서버 IP 혹은 터널 주소로 수시 업데이트됨.

  5. 웹 서버 및 네트워크 (Nginx)
   * 설정 파일: /etc/nginx/sites-available/myeongtae
   * 주요 블록:
       * /: 프론트엔드 정적 파일 서빙 (/var/www/myeongtae/web)
       * /api: 백엔드 리버스 프록시 (localhost:3000)
       * /uploads: 백엔드 이미지 정적 경로 (alias ~/Aek_Maki_Myeongtae/backend/uploads)
   * 권한 설정: Nginx(www-data) 접근을 위해 /home/ubuntu에 755 권한 부여됨.

  ---

  🛠 유지보수 및 트러블슈팅 가이드 (Gemini 전용)

  1. 로그 확인 및 모니터링
   - 실시간 API 로그: pm2 logs myeongtae-back
   - Nginx 에러 로그: sudo tail -f /var/log/nginx/error.log
   - DB 접속: psql -h localhost -U myeongtae_user -d myeongtae

  2. 코드 업데이트 절차 (CI/CD 미구축 시)
   1. Backend: git pull -> pm2 restart myeongtae-back
   2. Frontend: git pull -> npm run build -> sudo cp -r dist/web/* /var/www/myeongtae/web/ -> sudo systemctl restart nginx

  3. 현재 남아있는 과제 (Next Action)
   1. 도메인 구매: 도메인 구매 후 AWS Elastic IP 연결 필요.
   2. HTTPS 발급: certbot을 사용하여 SSL 인증서 적용 필요.
   3. AIT 번들 업데이트: api.ts의 BASE_URL을 최종 https://도메인으로 변경 후 다시 빌드하여 토스 콘솔에 업로드해야 함.

  ---

  ⚠️ 주의사항 (다음 개발자에게)
   * 인증서 유실 주의: backend/certs/ 폴더 내 파일은 Git에 없으므로 서버 이전 시 반드시 백업해야 함.
   * 권한 이슈: 403 Forbidden 발생 시 /var/www/myeongtae 소유권이 www-data인지, /home/ubuntu가 755인지 가장 먼저 확인할 것.
   * DB 방식: db.js가 Pool 객체를 반환하므로, 기존 client.connect() 코드는 필요 없으며 db.query()로 즉시 호출 가능함.
